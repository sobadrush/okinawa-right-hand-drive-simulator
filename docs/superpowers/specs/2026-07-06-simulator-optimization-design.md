# 沖繩右駕模擬器全面優化設計

日期：2026-07-06｜狀態：已核准（使用者選「全面優化」+「保留倒車鍵並補文件」）

## 範圍

單檔 `index.html`（Three.js r128 CDN）+ `README.md`。維持純靜態、GitHub Pages 可直接部署。不動：關卡判定座標、號誌規則、手機版佈局。

## A. 操控性

1. **Delta-time 物理**：`THREE.Clock` 取 dt，換算 `f = dt * 60`（每 60fps 幀等效係數）。所有每幀增量（加速、阻力、轉向、位移、stopTimer、對向車移動、方向燈計時）乘上 `f`；指數衰減改 `Math.pow(k, f)`。120Hz 螢幕行為與 60Hz 一致。
2. **轉向回正**：回正速率隨車速提高，消除高速漂移感。
3. **方向燈自動回正**：方向燈開啟時累積轉角 `turnAccum`；累積 > 約 57°（1.0 rad）且方向盤回中後自動熄燈。新增 `car.indicatorLatch` 記錄「本關曾打過的方向燈」，關卡判定改查 `indicator || indicatorLatch`，避免自動熄燈誤判「忘打方向燈」。
4. **倒車鍵**（S/↓）保留，補進畫面按鍵提示與 README。

## B. 畫面

1. `renderer.setPixelRatio(min(devicePixelRatio, 2))`（init + resize）。
2. 霧密度 0.015 → 0.0055，讓遠景可見；天空色不變。
3. 環境新增：人行道＋路緣（路口四角）、斑馬線、車道外側白實線、沖繩低層水泥建築（盒體＋窗）、雲朵、西側海面＋沙灘帶。
4. NPC 對向車改組合體（車身/車艙/車輪/車窗/頭燈），原點改地面（setup 中 y 0.8 → 0）。
5. 玩家第一人稱加引擎蓋網格，隨車位姿更新。
6. 號誌亮燈加 additive 光暈 sprite（含箭頭）。
7. 相機：FOV 隨速度 65→73 漸變；過彎微側傾。

## C. 遊戲性

1. **localStorage 星等**：key `okinawaRhdStars`；每關記錄最佳星等；下拉選單顯示 ⭐。
2. **星等**：本關扣分 0 → 3★；≤10 → 2★；其他 → 1★。通關視窗顯示本關星等。
3. **超速**：限速 40 km/h；HUD 加限速標誌；>40 速度數字變紅 + 警告條；持續超速每約 2.5 秒扣 5 分。
